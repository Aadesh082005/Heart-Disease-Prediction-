ABOUT THE PROJECT

Technology with a purpose.

CardioSense AI is an educational web application demonstrating how a saved machine-learning classifier processes cardiovascular feature values and returns a predicted class.

ML

Machine learning

Uses a Logistic Regression classifier trained on a labeled dataset.

SC

Feature scaling

Applies the saved StandardScaler before sending values to the model.

WEB

Web application

Flask handles form validation, prediction requests and result rendering.

METHODOLOGY

How the prediction works

  1. Input: collect 13 feature values from the assessment form.
  2. Validation: check that values are present and within configured bounds.
  3. Scaling: transform inputs using the saved training scaler.
  4. Inference: generate a class prediction and, when supported, a class probability.
  5. Presentation: display the model output and a reminder of its limitations.
i
Scope and limitations

This project is not a certified medical device. Model quality depends on the training data, preprocessing, feature definitions and validation. Its outputs must not be used for diagnosis or treatment decisions.
